把「零散的名詞與選擇題」串成一條學生看得懂的學習路徑：CPU → 指令 → 匯流排 → 記憶體 → I/O → 解題。

核心觀念：CPU 是「做事的人」、暫存器是「手邊的小空間」、記憶體是「工作資料區」、匯流排是「道路」、控制訊號是「交通指揮」。學生先建立這張圖，再放入名詞與計算題。

1微處理機基本概念

  • CPU 的基本結構：ALU、控制電路、暫存器
  • CPU 位元數與架構概念
  • 時脈、時脈週期與執行速度
  • Pipeline、超管線、超純量等速度提升概念
  • L1 Cache：降低 CPU 對外部記憶體存取時間
CPUClockPipelineCache

2CPU 裡面到底在做什麼？

  • PC：指向下一道指令所在位址
  • IR：暫存剛由記憶體讀入的指令
  • ACC：常用於 ALU 運算結果的暫存
  • Stack：副程式呼叫時可保存返回位址
  • Opcode：定義指令要做的動作
學生口訣：PC 找下一題 → IR 看題目 → 控制單元解讀 → ALU 做運算 → 暫存器放結果。

題目常把三個階段打亂，要求學生判斷正確順序。這是整章最值得先建立的「骨架」。

搭配 MOV 指令理解

MOV Acc, Data：可理解成把 Data 的資料轉移到 Acc。
MOV [OPR], AX：把 AX 內容寫入 OPR 所指定位址。

4三大匯流排：CPU 的道路

  • 位址匯流排：決定 CPU 能選到哪個位址；線數越多，可定址範圍越大。
  • 資料匯流排：負責資料傳送；寬度與一次可傳送的資料量有關。
  • 控制匯流排：傳送讀、寫、時脈等控制訊號。
解題重點：16 條位址線 → 2¹⁶ 個位址；24 條位址線 → 2²⁴ 個位址。

5記憶體：速度與角色

  • Register → Cache → RAM → ROM：題目中的速度比較
  • 程式執行前通常要先載入 RAM
  • RAM：可讀寫、揮發性
  • ROM：非揮發性，題目以保留資料的特性辨識
  • 輔助記憶體：容量大、價格低、可攜性佳，但速度通常較慢
RegisterCacheRAMROM

6記憶體容量與位址

  • 1K × 8：1024 個位址，每個位址 8 bits
  • 「容量」要拆成：位址數 × 每位址資料寬度
  • 由位址線數量推定可定址空間
  • 利用解碼器做記憶體擴充與選擇
解題三步驟：先看位址數 → 再看資料寬度 → 最後算總容量。

7I/O：CPU 如何與外界溝通？

  • Memory Mapped I/O：I/O 佔用記憶體位址空間
  • CPU 可用記憶體指令存取 I/O
  • 題目會用 I/O/M、RD、WR 判斷目前動作
  • 讀取：資料往 CPU；寫入：資料由 CPU 往外
判斷順序：先看 I/O 還是 Memory → 再看 RD / WR → 最後判斷資料方向。

8解碼器與位址解碼

  • 利用解碼器選擇特定記憶體或介面裝置
  • 固定地址解碼題：注意哪些位址線直接進入邏輯閘、哪些經過反相
  • 記憶體擴充題：同時考「容量」與「資料寬度」

🎯 升學解題架構：看到題目先分類

看到「線數」

先想到 位址空間 / 資料寬度。例如 16 條位址線 → 2¹⁶ 個位址。

看到「PC / IR / ACC」

先想到 CPU 內部資料流：PC 找指令、IR 放指令、ACC 常放運算結果。

看到「Read / Write」

先問 資料往哪裡走？ CPU 讀入，或 CPU 寫出。

看到「RAM / ROM / Cache」

先比較 速度、揮發性、用途，不要只背名稱。

看到「I/O/M、RD、WR」

先判斷 記憶體還是週邊，再判斷讀或寫。

看到「解碼器」

先想 選擇哪一顆晶片 / 哪個位址，再進一步做邏輯判斷。

👨‍🏫 建議的教學順序

  1. 先建立全貌：CPU、記憶體、I/O、匯流排。
  2. 再認識 CPU：PC、IR、ACC、控制單元、ALU。
  3. 再學指令：Fetch → Decode → Execute，搭配 MOV、ADD 等例子。
  4. 再學匯流排：位址、資料、控制三者分工。
  5. 再學記憶體：Register、Cache、RAM、ROM、容量計算。
  6. 最後進 I/O 與解碼：Memory Mapped I/O、RD/WR、位址解碼與記憶體擴充。
教學策略：不要一開始就讓學生背大量名詞。先用「CPU 做事 → 資料怎麼走 → 指令怎麼執行 → 怎麼找到資料」的故事線，再把考題放進去。
